Project

NixOS Homeserver

Zelfgehoste Linux-server voor media, opslag en netwerkdiensten.

Beschrijving

Voor dit project heb ik een thuisserver gebouwd op Linux. De server host verschillende diensten, waaronder bestandsopslag, mediahosting en netwerktools. Veiligheid werd voorzien door middel van firewallregels, gebruikersbeheer en regelmatige updates. Dit project heeft mijn kennis van Linux, virtualisatie en systeembeheer aanzienlijk versterkt.
